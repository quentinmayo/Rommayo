# Contributing

Bug reports, accessibility improvements, emulator compatibility reports and code contributions are welcome. Include your Rommayo version, RomM version, device/OS and WebView version, plus reproducible steps with synthetic or authorized content.

Run `npm test`, `npm run test:desktop`, and Android build/lint for affected platforms. Preserve access to the complete RomM interface. Keep native capabilities narrow, validate external origins, and keep passwords and server-specific data out of commits and logs.

Do not upload ROMs, BIOS files, decryption keys or private collection screenshots with reports. Rommayo does not support sourcing copyrighted game content or third-party ROM download services.
